# Discord Бот для Ареста Участников

Discord бот на Python для временного ареста участников голосовых каналов с управлением ролями, системой апелляций и мультисерверной поддержкой.

## Возможности

- 🚔 Арест участников через slash-команду `/arrest` (или префиксную `!арест`)
- ⏱️ Настраиваемые пресеты времени ареста (autocomplete по пресетам гильдии)
- 🔒 Автоматическое управление ролями одним вызовом (снятие всех ролей и выдача роли заключенного; managed-роли и роли выше роли бота сохраняются)
- 🔐 **Автоматическая настройка прав доступа** — роль заключённого блокируется от всех голосовых каналов кроме тюрьмы (настраивается в фоне, уже корректные каналы пропускаются)
- 📍 Перемещение в специальный канал «тюрьмы» (только если участник в войсе; арест работает и для участников вне голосовых каналов)
- ⏰ Автоматическое освобождение по истечении времени (единый фоновый цикл проверки каждые 10 секунд, переживает рестарт бота)
- 🔓 Досрочное освобождение через `/release` (или `!освободить`)
- 😴 Отключение из голосового канала через `/sleep` (или `!спать`)
- 🎙️ Опциональная команда **«Подтянись-ка»** — бот заходит в голосовой канал автора или указанного участника и всегда остаётся с выключенными микрофоном и аудиоприёмом
- ⚖️ **Система апелляций через модальное окно** — арестованный вводит текст апелляции в Modal
- 🗳️ Публичное голосование за/против освобождения с **живым счётчиком голосов** на кнопках
- 🎨 **Красивые Embeds** — арест (красный), освобождение (зелёный), голосование (синий), с аватаром участника и Discord-таймстампами (`<t:...:R>`)
- ♻️ **Persistent-кнопки** — кнопка «Подать апелляцию» и кнопка «Открыть панель» работают даже после рестарта бота
- 🌐 **Мультисерверная поддержка** — каждый сервер имеет свои настройки
- ⚙️ **Панель настроек** через slash-команду `/jail-config` (embed-интерфейс)
- 💾 **Асинхронная база данных SQLite** (aiosqlite, WAL-режим)

## Требования

- **Python 3.10 или выше**
- discord.py 2.4.0 или выше с voice-зависимостями
- aiosqlite 0.20.0 или выше

## Установка

1. Клонируйте или скачайте файлы проекта

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Создайте файл `config.json` на основе `config.example.json`:
```json
{
  "bot_token": "YOUR_BOT_TOKEN_HERE",
  "command_prefix": "!"
}
```

Поля конфига:
- `bot_token` — токен бота из Discord Developer Portal
- `command_prefix` — префикс для текстовых команд (по умолчанию `!`)

4. Настройте бота через панель настроек `/jail-config`

### Создание и настройка бота в Discord Developer Portal

#### 1. Создание приложения

1. Перейдите на [Discord Developer Portal](https://discord.com/developers/applications)
2. Нажмите **"New Application"**
3. Введите имя приложения и нажмите **"Create"**

#### 2. Настройка Bot

1. Перейдите в раздел **"Bot"** в левом меню
2. Нажмите **"Reset Token"** и скопируйте токен
3. Вставьте токен в поле `bot_token` в `config.json`

#### 3. Включение Privileged Gateway Intents

В разделе **"Bot"** включите:

- ✅ **SERVER MEMBERS INTENT** — **ОБЯЗАТЕЛЬНО** для работы с участниками сервера
- ✅ **MESSAGE CONTENT INTENT** — требуется для префиксных команд (`!арест` и т.д.) и mention-команды «Подтянись-ка»
- ⚪ **PRESENCE INTENT** — не требуется

#### 4. Настройка OAuth2 и прав бота

1. Перейдите в раздел **"OAuth2"** → **"URL Generator"**
2. В **"SCOPES"** выберите: `bot`, `applications.commands`
3. В **"BOT PERMISSIONS"** выберите:
   - ✅ **Manage Roles** — для снятия/выдачи ролей
   - ✅ **Manage Channels** — для создания каналов и настройки прав доступа
   - ✅ **View Channels** — для доступа к каналам
   - ✅ **Send Messages** — для уведомлений
   - ✅ **Read Message History** — для работы с сообщениями
   - ✅ **Connect** — для опциональной функции «Подтянись-ка»
   - ✅ **Move Members** — для перемещения в тюрьму

   **Speak** для этой функции не требуется: бот подключается с выключенными микрофоном и аудиоприёмом.
4. Скопируйте сгенерированную ссылку и добавьте бота на сервер

#### 5. Иерархия ролей на сервере

**КРИТИЧЕСКИ ВАЖНО:** роль бота должна быть **выше** роли заключенного и всех ролей, которые он будет снимать с участников:

```
👑 Владелец сервера
🤖 Роль бота          ← должна быть здесь
👮 Администратор
👤 Участник
🔒 Заключенный        ← ниже роли бота
@everyone
```

Managed-роли (роли ботов/интеграций) снять невозможно — бот корректно сохраняет их при аресте.

## Команды

### Slash-команды (рекомендуется)

| Команда | Описание |
|---|---|
| `/arrest member: duration:` | Арестовать участника. `duration` — autocomplete по пресетам гильдии («5 минут» и т.д.). Участнику не обязательно быть в голосовом канале — роль снимается/выдаётся в любом случае, перемещение в тюрьму происходит только если он в войсе. |
| `/release member:` | Досрочно освободить участника |
| `/sleep member:` | Отключить участника из голосового канала. Параметр опционален — без него откроется список участников голосовых каналов. |
| `/jail-config` | Открыть панель настроек бота (только для админов) |

### Префиксные команды (сохранены для совместимости)

| Команда | Описание |
|---|---|
| `!арест` | Выбор участника своего голосового канала через выпадающий список, затем выбор срока |
| `!освободить @участник` | Досрочное освобождение |
| `!спать [@участник]` | Отключение из голосового канала (без участника — выпадающий список) |

### «Подтянись-ка» (опционально)

Функция выключена по умолчанию для каждого сервера. Включить её можно в `/jail-config` кнопкой **🎙️ Подтянись-ка**, затем нужно нажать **💾 Сохранить**.

Команды работают только при прямом упоминании бота:

- `@Робот подтянись-ка` — бот подключается к голосовому каналу автора сообщения.
- `@Робот подтянись-ка к @Вася` — бот подключается к голосовому каналу указанного участника.
- `@Робот выйди` — отключает бота из голосового канала.

Призвать бота может любой участник, но выйти по команде может только владелец сервера, участник с правом **Administrator** или **Moderate Members**, участник с настроенной админской ролью, а также встроенный супер-администратор бота. Если автор или указанный участник не находятся в голосовом канале, бот сообщает об этом и не подключается.

## Настройка через панель

Администратор сервера использует slash-команду:
```
/jail-config
```

Откроется embed-панель настроек с текущим состоянием конфигурации и кнопками разделов.

### Разделы

- **📺 Каналы** — канал тюрьмы (голосовой), канал для подачи апелляций, канал голосования. Выбор через селекты или создание новых каналов через модальное окно.
- **👥 Роли** — роль заключенного (выбор/создание), дополнительные админские роли.
- **🎙️ Подтянись-ка** — включение/выключение опционального подключения бота к голосовым каналам.
- **⏱️ Сроки ареста** — добавление/изменение/удаление пресетов (название + секунды, максимум 25).
- **⚖️ Апелляции** — время голосования для каждого пресета (`0` = апелляция недоступна).

### Кнопки управления

- **💾 Сохранить** — валидация и запись в БД. Права каналов для роли заключённого настраиваются **в фоне** (уже корректно настроенные каналы пропускаются).
- **↩️ Отменить изменения** — откат черновика к последним сохранённым настройкам (без обращения к БД).
- **🏭 Сброс к заводским** — двухшаговый сброс с экраном подтверждения («Да, сбросить» / «Отмена»): все настройки сервера удаляются и создаются заново по умолчанию.
- **❌ Закрыть** — закрытие панели (только если нет несохранённых изменений).

При бездействии панель автоматически деактивируется (кнопки дизейблятся по таймауту).

## Система апелляций

После ареста в канал уведомлений отправляется **красный embed** с полями «Кого», «Кем», «Срок», «Освобождение» (Discord-таймстамп `<t:...:R>`) и persistent-кнопкой **«Подать апелляцию»**.

1. **Кнопка «Подать апелляцию»** — доступна только арестованному. Работает даже после рестарта бота (данные ареста берутся из БД).
2. **Модальное окно** — арестованный вводит текст апелляции в многострочное поле (до 1000 символов). Никаких сообщений в чат писать не нужно.
3. **Голосование** — в канал голосования отправляется **синий embed** с текстом апелляции и дедлайном (`<t:...:R>`). Кнопки показывают живой счётчик: «✅ Выпустить (N)» / «❌ Не выпускать (N)». Можно переголосовать; заключенные голосовать не могут.
4. **Результат** — по истечении времени публикуется embed с итогами (зелёный при освобождении, красный при отказе). При «за» ≥ «против» — заключенный освобождается.

Ограничения: одна апелляция на арест; апелляция может быть недоступна для коротких сроков (настраивается).

## Хранение данных и совместимость

Настройки хранятся в SQLite (`jail_bot.db`), доступ асинхронный через **aiosqlite**, включён режим **WAL**.

> ℹ️ **Заметка о WAL:** после первого запуска рядом с базой появятся файлы `jail_bot.db-wal` и `jail_bot.db-shm` — это нормально, их не нужно удалять.

Схема БД совместима со старой версией бота: таблицы `guild_settings`, `arrest_durations`, `appeal_voting_durations`, `active_arrests` не переименовывались. Старые записи `release_timestamp` без таймзоны читаются как UTC; новые записи хранятся в ISO-формате с таймзоной.

## Технические детали

**bot.py:**
- `JailBot(commands.Bot)` — подкласс с `setup_hook`: подключение БД, `tree.sync()`, регистрация persistent views
- `AppealButton(discord.ui.DynamicItem)` — persistent-кнопка апелляции (`custom_id=appeal_{member_id}`)
- `AppealModal` — модальное окно ввода текста апелляции
- `AppealVotingView` — голосование с живым счётчиком
- `MemberSelectView` / `SleepMemberSelectView` — выбор участника через `discord.ui.Select`
- `check_expired_arrests` — единственный механизм освобождения (`tasks.loop`, 10 сек)
- `arrest_locks` / `appeal_locks` — `defaultdict(asyncio.Lock)` против race conditions
- Роли меняются одним вызовом `member.edit(roles=[...])`

**database.py:**
- `Database` — async-класс (aiosqlite), одно постоянное соединение (`connect()` / `close()`)
- `PRAGMA journal_mode=WAL`, `synchronous=NORMAL`, `foreign_keys=ON`
- Таймстампы — `datetime.now(timezone.utc)`, ISO-формат с таймзоной

**config_ui.py:**
- `MainConfigPanel` — панель настроек, все экраны — `discord.Embed`
- `PanelView` — общий View с `on_timeout` (дизейбл элементов)
- `ConfigDraft` — черновики для безопасного редактирования
- Настройка прав каналов — `asyncio.create_task` в фоне, логирование через `logging`

## Устранение неполадок

### Бот не отвечает на команды
- Проверьте токен и префикс в `config.json`
- Убедитесь, что у бота есть права на чтение сообщений

### Slash-команды не появляются
- Убедитесь, что бот приглашён со scope `applications.commands`
- Подождите: Discord может кэшировать список команд до часа
- Перезапустите бота (`tree.sync()` выполняется при старте в `setup_hook`)

### Бот не может переместить участника / управлять ролями
- Роль бота должна быть выше роли участника и роли заключенного
- Проверьте права «Перемещать участников» и «Управление ролями»
- Проверьте настройки в `/jail-config`

### Кнопка апелляции не работает после рестарта
- Кнопка persistent и должна работать. Если арест завершился — бот сообщит «Ваш арест уже завершен»

### Ошибка «Настройки не найдены»
- Откройте `/jail-config` — настройки создадутся автоматически
- Проверьте, что файл `jail_bot.db` не поврежден
